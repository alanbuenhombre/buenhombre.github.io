El PDF se genera con el diálogo de impresión del navegador: elige Guardar como PDF, márgenes Ninguno y activa Gráficos de fondo. El paquete de Figma se abre con el plugin Med · Importador (carpeta figma-plugin).

Del documento del equipo a una diagramación editorial, sin que la información salga de este computador.

  1. Carga un Word, PDF o texto.
  2. Med reconoce títulos, entradillas, listas, tablas, citas e imágenes.
  3. Elige formato (carta, media carta, tabloide, widescreen, mobile) y plantilla.
  4. Exporta el PDF o el paquete editable para Figma, y termina el detalle allá.
